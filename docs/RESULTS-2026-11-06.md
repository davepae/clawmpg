# AI coding agents compared: Copilot CLI vs Claude Code, same model

*Early results from a small, single-model benchmark (OpenClaw Efficiency Rating, OER). Preliminary, not an official rating.*

## What we tested

Both tools ran **Claude Sonnet 5.5 at medium effort**, so differences come from the tool and plan, not the model. Each ran the same 7 coding tasks (small bug fixes through a multi-file feature) in a clean copy of a small Python library. Hidden tests, which the agent never sees, decided pass or fail.

The suite represents about **9 "OpenClaw Miles" (OCM)**. One OCM is what a reference engineer completes, verified, in 30 minutes, so the suite is about 4.5 hours of human work.

## Best run of each (2026-11-06)

| | GitHub Copilot CLI | Claude Code |
|---|---|---|
| Tasks passed | 7/7 | 7/7 |
| Human interventions needed | 0 | 0 |
| Cost for the whole suite | **about $0.37** | about $0.52 |
| Verified work per dollar | **24.3 OCM/$** | 17.2 OCM/$ |
| Verified work per hour | **296 OCM/hr** | 213 OCM/hr |
| Time for the suite | about 110 s | about 150 s |
| Sessions per budget (projected) | 27 on $10 | 38 on $20 |
| Estimated monthly cost (40 sessions) | $15 | $21 |

Run ids: Copilot `25b302a8d724`, Claude `cb8381a0f9f5`. Repeat runs landed close to these: Copilot at $0.37-$0.41 per suite and Claude at $0.52-$0.53.

## Takeaways

- **Both finished everything**, with no human rescue and the model confirmed by each tool.
- **Copilot was about 30% cheaper per unit of work and about 40% faster** in these runs. Both ran the same model, so this reflects each tool's overhead and the number of calls it makes.
- **The benchmark is too easy to rank them by score.** Both score 100/100, because both finished far inside the cost and time reference targets. The tasks need to be harder before the score separates them.

## Caveats

- **Different cost bases.** Copilot's cost is the usage the CLI reports, converted at $0.01 per credit, and it matched the account's usage counter in our checks. Claude's is an API-equivalent figure. Its Pro plan had hit its weekly limit, so these runs were billed as extra usage (`billing_mode: extra_usage`), and what Anthropic actually charged is unverified.
- **GitHub's billing API disagreed with the CLI.** A cross-check against GitHub's AI-credit usage API showed more usage than the CLI reported ($0.90 against $0.39 for one full suite) and was still catching up hours later. The cause is unresolved, so Copilot's cost is not independently confirmed. The API lags by well over 16 minutes and updates in batches (see SPEC section 6.2).
- **Small and noisy.** One small codebase of about 70 lines, 7 tasks, one session per tool, and human-time baselines estimated by the author. Single tasks varied by up to 2x between identical runs.
- **Plan limits are unmeasured.** The "sessions per budget" figures are projections, not measured limits.

*Data: OER suite v0.1.0, Copilot CLI 1.0.105-1.0.106, Claude Code 2.1.311, run on 2026-11-06. Costs include only the agent's usage, not the human's time.*
